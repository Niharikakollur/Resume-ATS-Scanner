# Resume ATS Scanner Web App

A smart Resume ATS (Applicant Tracking System) Scanner built using **Python, Flask, and PyPDF2**.

This app analyzes resumes based on company-specific requirements and gives an **ATS score** with approval/rejection result.

## 🚀 Live Demo
👉 https://resume-ats-scanner.onrender.com

## ✨ Features
- Upload resume (PDF)
- Select company
- ATS score calculation
- Smart keyword checking
- Clean professional UI

## 🛠 Tech Stack
- Python
- Flask
- PyPDF2
- HTML, CSS
